Session 1: Network Fundamentals & OSI Model

مرجع تفاعلي أساسيات الشبكات، مكوناتها، ونموذج الاتصال السباعي

🌐 1. مفهوم الشبكات (What is a Network)

  • التعريف: ربط مجموعة من الأجهزة (Computers, Printers, Servers) معاً بغرض مشاركة الموارد (Resources) وتبادل البيانات والمعلومات بكفاءة وأمان.
  • الهدف الرئيسي: سهولة التواصل، تقليل التكلفة، المركزية في إدارة البيانات، وحفظ النسخ الاحتياطية.

💻 2. مكونات الشبكة (Network Components) وعلاقة Client/Server

  • مكونات الشبكة: أجهزة طرفية (End Devices)، أجهزة ربط وسطية (Switches, Routers)، ووسائط نقل (كابلات أو لاسلكي).
  • العميل (Client): الجهاز أو البرنامج اللي بيطلب الخدمة (زي متصفح الويب عندك لما يطلب صفحة من موقع).
  • الخادم (Server): الجهاز العملاق أو القوي اللي بيستقبل الطلبات وبيقدم الخدمات والبيانات للعملاء.

🧱 3. نموذج الاتصال (OSI Model - 7 Layers)

انقر على أي طبقة لاستعراض تفاصيلها ووظيفتها:

Layer 7: Application Layer (طبقة التطبيقات) ▼
الواجهة اللي بيتعامل معاها المستخدم مباشرة (زي المتصفح وبرامج البريد الإلكتروني HTTP, FTP, DNS).
Layer 6: Presentation Layer (طبقة العرض) ▼
مسؤولة عن تنسيق البيانات، التشفير (Encryption)، وضغط البيانات (Compression) عشان تفهمها البرامج.
Layer 5: Session Layer (طبقة الجلسات) ▼
بفتح وإدارة وإغلاق جلسات الاتصال بين الأجهزة وتأمين استمراريتها أثناء نقل الداتا.
Layer 4: Transport Layer (طبقة النقل) ▼
بتقطع الداتا لقطعت صغيرة (Segments) وبتتأكد من وصولها سليمة وبدون أخطاء عبر بروتوكولات مثل TCP و UDP.
Layer 3: Network Layer (طبقة الشبكة) ▼
مسؤولة عن توجيه البيانات عبر الشبكات المختلفة باستخدام عناوين الـ IP واختيار أقصر طريق (Routing).
Layer 2: Data Link Layer (طبقة ربط البيانات) ▼
بتعامل الداتا على شكل Frames وبتستدم الـ MAC Address عشان تنقل البيانات بين الأجهزة في نفس الشبكة المحلية (LAN).
Layer 1: Physical Layer (الطبقة الفيزيائية) ▼
الطبقة السفلى الخاصة بنقل البيانات على شكل إشارات كهربائية أو ضوئية عبر الكابلات أو اللاسلكي.
