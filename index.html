Network Camp - المرجع الشامل

مرجع مهندسي الشبكات يضم تفاصيل السيشن الأولى والسيشن الثانية بالكامل

🌐 أولاً: السيشن الأولى (أساسيات الشبكات والـ OSI)
1. مفهوم الشبكة (Network Definition)

الشبكة هي ربط جهازين أو أكثر معاً بهدف رئيسي وهو المشاركة (Sharing) سواء للموارد (طابعات، البيانات، ملفات)، أو الخدمات (إنترنت).

💻 الأجهزة (Devices)

أجهزة طرفية (End Devices) وأجهزة ربط (Intermediary).

📡 الوسائط (Media)

الكابلات النحاسية، الألياف الضوئية، أو الموجات اللاسلكية.

📋 البروتوكولات (Protocols)

اللغة المشتركة والقواعد المنظمة لنقل البيانات (مثل TCP/IP).

2. أنواع الشبكات حسب الحجم (Network Scope)
PAN (Personal Area Network)

شبكة شخصية (أمتار)، مثل: سماعة بلوتوث، ماوس وايرلس.

LAN (Local Area Network)

شبكة محلية (مبنى/منزل)، مثل: راوتر البيت والأجهزة المتصلة.

CAN (Campus Area Network)

شبكة حرم جامعي/شركة، ربط عدة مباني متقاربة.

MAN (Metropolitan Area Network)

شبكة مدينة، ربط فروع شركة داخل نفس المدينة.

WAN (Wide Area Network)

شبكة واسعة (دول/قارات)، مثل: الإنترنت وربط الفروع البعيدة.

3. أجهزة الشبكة (Network Devices)
Switch

✓ يربط الأجهزة في نفس الشبكة (LAN).
✓ جهاز ذكي، بيتعامل بالعنوان الفيزيائي (MAC Address).
✓ يرسل البيانات للوجهة فقط (Unicast) بلا زحمة.

Router

✓ يربط شبكات مختلفة ببعضها (WAN).
✓ بيتعامل بالعنوان المنطقي (IP Address).
✓ يختار "أفضل مسار" لنقل البيانات (Routing).

Hub

✕ جهاز قديم (غبي)، لا يفهم العناوين.
✕ يرسل البيانات للجميع (Broadcast).
✕ يسبب بطء وتصادم للبيانات (Collision).

Access Point & Modem & Firewall

Access Point: تحويل السلكي لاسلكي.
Modem: ترجمة الإشارات الرقمية والتناظرية.
Firewall: الجدار الناري لحراسة أمن الشبكة.

🧱 نموذج OSI (The 7 Layers) - اضغط لتوسيع التفاصيل
L7. Application Layer (طبقة التطبيقات)▼

الوظيفة: الواجهة المباشرة للمستخدِم، توفر خدمات الشبكة للتطبيقات.

Data PDU: Data

أمثلة: HTTP, HTTPS, FTP, SMTP

L6. Presentation Layer (طبقة التهيئة)▼

الوظيفة: ترجمة، ضغط، وتشفير البيانات لتكون مفهومة للطرف الآخر.

Data PDU: Data

أمثلة: JPEG, ASCII, SSL/TLS Encryption

L5. Session Layer (طبقة الجلسة)▼

الوظيفة: فتح، إدارة، وإغلاق الجلسات (Sessions) بين التطبيقات.

Data PDU: Data

أمثلة: NetBIOS

L4. Transport Layer (طبقة النقل)▼

الوظيفة: تقطيع البيانات، ضمان الوصول (TCP) أو السرعة (UDP).

Segment PDU: Segment

العنوان (Address): Port Number

L3. Network Layer (طبقة الشبكة)▼

الوظيفة: التوجيه (Routing) واختيار أفضل مسار. جهاز الراوتر يعمل هنا.

Packet PDU: Packet

العنوان (Address): IP Address (Logical)

L2. Data Link Layer (طبقة ربط البيانات)▼

الوظيفة: اكتشاف الأخطاء في الشبكة المحلية، جهاز السويتش يعمل هنا.

Frame PDU: Frame

العنوان (Address): MAC Address (Physical)

L1. Physical Layer (الطبقة الفيزيائية)▼

الوظيفة: تحويل البيانات لنبضات (كهرباء/ضوء/موجات) ونقلها في السلك.

Bits PDU: أصفار ووحايد (0s and 1s)

الأجهزة/الكابلات: Cables, Hub, Connectors

📐 7. الهيكل الهندسي للشبكة (Network Topologies)
Star Topology

جهاز مركزي (Switch) تتصل به جميع الأجهزة بشكل مستقل. (الأكثر استخداماً). عطل كابل لا يؤثر، وعطل المركزي يسقط الشبكة.

Mesh Topology

كل جهاز متصل بكل الأجهزة الأخرى لضمان الاستقرار وعدم انقطاع الشبكة (Redundancy)، لكن بتكلفة عالية.

Bus Topology

كابل رئيسي واحد متصل به جميع الأجهزة (شبه منقرض)، قطع الكابل يوقف الشبكة بالكامل.

Ring Topology

حلقة مغلقة والبيانات تسير في اتجاه واحد، عطل جهاز يكسر الحلقة.

🌐 ثانياً: السيشن الثانية تُستخدم في السيشن الثانية
1. مفاهيم الـ IPv4 والـ Subnetting تُستخدم في السيشن الثانية

• إجمالي العناوين $2^{32}$ (حوالي 4.3 مليار عنوان).

• سر الـ (-2): خصم عنوانين أساسيين لكل بلوك وهما الـ Network ID والـ Broadcast Address.

• بروتوكول الـ ARP: لحل معضلة ربط الـ IP بالـ MAC Address في الشبكة المحلية (ARP Request و ARP Reply).

• حالات خاصة: APIPA (`169.254.x.x`) عند غياب الـ DHCP.
