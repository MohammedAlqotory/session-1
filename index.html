ملخص أساسيات الشبكات

المرجع السريع لمهندسي الشبكات، يضم مفاهيم السيشن الأولى من الأجهزة وأنواع الشبكات وحتى نموذج OSI.

🌐 1. مفهوم الشبكة (Network Definition)

الشبكة هي ربط جهازين أو أكثر معاً بهدف رئيسي وهو المشاركة (Sharing) سواء للموارد (طابعات، البيانات، ملفات)، أو الخدمات (إنترنت).

💻 الأجهزة (Devices)

أجهزة طرفية (End Devices) وأجهزة ربط (Intermediary).

📡 الوسائط (Media)

الكابلات النحاسية، الألياف الضوئية، أو الموجات اللاسلكية.

📋 البروتوكولات (Protocols)

اللغة المشتركة والقواعد المنظمة لنقل البيانات (مثل TCP/IP).

📊 2. أنواع الشبكات حسب الحجم (Network Scope)
PAN (Personal Area Network)

شبكة شخصية (أمتار)، مثل: سماعة بلوتوث، ماوس وايرلس.

LAN (Local Area Network)

شبكة محلية (مبنى/منزل)، مثل: راوتر البيت والأجهزة المتصلة.

CAN (Campus Area Network)

شبكة حرم جامعي/شركة، ربط عدة مباني متقاربة.

MAN (Metropolitan Area Network)

شبكة مدينة، ربط فروع شركة داخل نفس المدينة.

WAN (Wide Area Network)

شبكة واسعة (دول/قارات)، مثل: الإنترنت وربط الفروع البعيدة.

⚙️ 3. أجهزة الشبكة (Network Devices)
Switch

✓ يربط الأجهزة في نفس الشبكة (LAN).
✓ جهاز ذكي، بيتعامل بالعنوان الفيزيائي (MAC Address).
✓ يرسل البيانات للوجهة فقط (Unicast) بلا زحمة.

Router

✓ يربط شبكات مختلفة ببعضها (WAN).
✓ بيتعامل بالعنوان المنطقي (IP Address).
✓ يختار "أفضل مسار" لنقل البيانات (Routing).

Hub

✕ جهاز قديم (غبي)، لا يفهم العناوين.
✕ يرسل البيانات للجميع (Broadcast).
✕ يسبب بطء وتصادم للبيانات (Collision).

Access Point

نقطة وصول لتحويل الشبكة السلكية إلى لاسلكية (Wi-Fi) للسماح بتوصيل الهواتف والأجهزة بدون كابلات.

Modem

مترجم الإشارات (Modulator/Demodulator) بين الإشارة الرقمية للكمبيوتر والإشارة التناظرية لخطوط التليفون.

Firewall

الجدار الناري، حارس أمن الشبكة. يراقب البيانات الداخلة والخارجة ويمنع الاختراقات بناءً على قواعد محددة.

🔌 4. وسائط النقل (Transmission Media)
سلكي (Wired)
Twisted Pair (UTP/STP)

كابلات نحاس مجدولة (Ethernet) تُستخدم في الـ LAN. تنقل نبضات كهربائية. (Cat5e, Cat6).

Fiber Optics

ألياف ضوئية. سرعات فائقة ومسافات طويلة، تنقل البيانات كنبضات ضوء. (Single-mode, Multi-mode).

لاسلكي (Wireless)

تعتمد على موجات الراديو لنقل البيانات في الهواء، توفر حرية الحركة (Mobility).

أمثلة: Wi-Fi, 4G/5G, Bluetooth

العيوب: عرضة للتشويش والتداخل، وأقل أماناً من السلكي.

🤝 5. نموذج الخادم والعميل (Client-Server Model)
Client (العميل)

الجهاز أو البرنامج الذي يطلب (Request) الخدمة (مثل المتصفح).

Request ⇄ Response
Server (الخادم)

الجهاز القوي الذي يعالج الطلب ويرد (Response) بالبيانات (Web Server, File Server).

🧱 6. نموذج OSI (The 7 Layers)

اضغط على أي طبقة لرؤية التفاصيل (من الطبقة 7 إلى 1):

L7. Application Layer (طبقة التطبيقات) ▼
الواجهة اللي بيتعامل معاها المستخدم مباشرة (HTTP, FTP, DNS).
L6. Presentation Layer (طبقة التهيئة) ▼
مسؤولة عن تنسيق البيانات، التشفير (Encryption)، وضغط البيانات.
L5. Session Layer (طبقة الجلسة) ▼
فتح وإدارة وإغلاق جلسات الاتصال بين الأجهزة وتأمين استمراريتها.
L4. Transport Layer (طبقة النقل) ▼
بتقطع الداتا لقطع (Segments) وبتتأكد من وصولها سليمة عبر TCP و UDP.
L3. Network Layer (طبقة الشبكة) ▼
توجيه البيانات عبر الشبكات باستخدام عناوين الـ IP واختيار أقصر مسار (Routing).
L2. Data Link Layer (طبقة ربط البيانات) ▼
تعامل الداتا على شكل Frames واستخدام الـ MAC Address لنقلها في الـ LAN.
L1. Physical Layer (الطبقة الفيزيائية) ▼
نقل البيانات على شكل إشارات كهربائية أو ضوئية عبر الكابلات أو اللاسلكي.
📐 7. الهيكل الهندسي للشبكة (Network Topologies)
Star Topology

جهاز مركزي (Switch) تتصل به جميع الأجهزة بشكل مستقل. (الأكثر استخداماً).

✓ ميزة: عطل كابل واحد لا يؤثر على باقي الشبكة.

✕ عيب: إذا تعطل الجهاز المركزي تقع الشبكة كاملة.

Mesh Topology

كل جهاز متصل بكل الأجهزة الأخرى. تستخدم في شبكات WAN لضمان الاستقرار.

✓ ميزة: لا تقع الشبكة أبداً لوجود مسارات بديلة (Redundancy).

✕ عيب: التكلفة عالية جداً وكمية كابلات ضخمة.

Bus Topology

كابل رئيسي واحد متصل به جميع الأجهزة. (شبه منقرض).

✓ ميزة: رخيص وسهل التركيب.

✕ عيب: قطع الكابل يوقف الشبكة، وزحمة في نقل البيانات.

Ring Topology

الأجهزة متصلة في حلقه مغلقة والبيانات تسير في اتجاه واحد.

✓ ميزة: لا يوجد تصادم للبيانات.

✕ عيب: عطل جهاز واحد يكسر الحلقة ويوقف الشبكة.
